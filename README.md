# leetcode-daily

This repo is where I practice LeetCode problems day by day.

The goal is not just to solve the problem, but to practice how I think. For each problem I write down what I learned, how I solved it, what other ways there are to solve it, and which one is better and why.

## What I track for each problem

- The problem and what it's really asking
- My first idea (even if it's not the best one)
- The solution I ended up using
- Time and space complexity
- Other ways to solve it (based/best/worse), when the problem has more than one approach
- Any pattern or trick I want to remember for next time


## Why I'm doing this

I'm doing this to train how I think, not to memorize solutions. The point is to get better at breaking a problem down, spotting patterns, and comparing different ways to solve it.
